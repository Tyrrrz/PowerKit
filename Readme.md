**PowerKit** (formerly [**Tyrrrz.Extensions**](https://nuget.org/packages/Tyrrrz.Extensions)) is a collection of general-purpose utilities and extensions for rapid development with .NET.

**See also**:

- 📦 [PowerKit.Json](PowerKit.Json) — provides utilities and extensions for `System.Text.Json` types

## Install

- 📦 [NuGet](https://nuget.org/packages/PowerKit): `dotnet add package PowerKit`

> [!TIP]
> You can use [**Binternal**](https://github.com/Tyrrrz/Binternal) to internalize this library if you prefer to avoid taking an external dependency.
